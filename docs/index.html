Minecraft 1.20.1 · Forge / Fabric 同包

BBS Geo 模型导入器

将 Mod 中的模型导入 BBS，按来源分类查看。

仅支持 Mod 中的 Geo 格式模型（.geo.json）。

前往 GitHub 下载 在 Releases 中下载 JAR。

如何使用

  1. 安装导入器。将 bbs-geo-importer.jar 直接放入已安装 BBS 的游戏实例的 mods 文件夹，不用解压。Fabric 还需安装 Fabric API。
  2. 添加模型。以 Forge 1.20.1 为例：

    能正常安装的 Mod：把它的 JAR 放进 mods 即可，不用解压。如果只想用模型，也可以按下面的方法解压。

    版本或加载器不兼容的 Mod：在 mods 下新建一个文件夹，把它的 JAR 解压进去，保留 assets 的原有结构，例如 mods/模型包/assets/。原 JAR 留在 mods 外；这样只导入模型资源，不运行原 Mod。

  3. 重新启动游戏。按 B 打开 BBS 模型列表，在对应 Mod 的分类中查看模型。

主要功能

按 Mod 显示或隐藏
在 BBS 设置右侧点击文件夹图标，打开「Mod 模型管理」，即可切换整组模型的显示状态。
使用原包贴图
多个模型可以共用一张原图；有明确对应关系的多套皮肤可分别选择。可识别的分帧贴图取静态帧展示。
每次启动只扫描一次
打开或滚动模型列表不会重新扫描。新增的模型来源在下次启动时识别。
